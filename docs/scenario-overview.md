# Scenario Overview — TechPay Solutions Entra ID Lab

## Company Profile
- **Name**: TechPay Solutions S.L.
- **Sector**: Financial Technology (Fintech)
- **Employees**: 50
- **Location**: Barcelona, Spain
- **Services**: Digital payment processing, peer-to-peer 
  transfers, virtual card issuing

## Identity Management Context
TechPay uses Microsoft Entra ID as its central Identity 
Provider (IdP). All employee identities, access rights and 
authentication policies are managed from a single platform.

## Identity Architecture
| Component | Purpose |
|---|---|
| Users | Individual employee identities |
| Security Groups | Team-based access management |
| Roles | Permission sets following least privilege |
| Audit Logs | Full trail of all identity changes |

## Regulatory Context
| Regulation | Identity Requirement |
|---|---|
| GDPR Art. 25 | Privacy by Design — minimum access |
| GDPR Art. 32 | Unique accounts, MFA, access control |
| GDPR Art. 5(1)(f) | Integrity and confidentiality |
| DORA Art. 9 | ICT access control requirements |
| ENS (Spain) | Identity management controls |
